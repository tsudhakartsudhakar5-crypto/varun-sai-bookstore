# VARUN SAI BOOKSTORE

The independent official bookstore of author Varun Sai.

## Current stage
This is the public-facing Phase 1 foundation. It includes:
- Responsive homepage
- Book catalogue with search
- About and Contact placeholder pages
- External retailer links for *The Time Changes*
- Placeholder listing for *Learn It. Build It. Master It.*

## Important
This version does **not** yet include administrator login, database, eBook uploads, payments, secure downloads, reviews, or reader messaging. Those require a backend and will be developed in later phases. Do not upload paid eBook files into this public GitHub repository.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

After deployment, the site should be available at:
`https://tsudhakartsudhakar5-crypto.github.io/varun-sai-bookstore/`

GitHub Pages can host the static website only. Secure author login, private file storage, payments and order verification will need backend services in a later phase.
